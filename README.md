🧾 Bill Management System – Tkinter GUI Project

This is a Python GUI-based Bill Management System built using the Tkinter library. The application simulates a digital billing counter where users can enter the quantity of menu items and calculate the total bill in real-time.
________________________________________

💻 Features

•	📋 Menu Display: Shows a stylish menu card with item names and prices.

•	✍️ Input Section: Users can input quantities for:
o	Dosa
o	Cookies
o	Tea
o	Coffee
o	Juice
o	Pancakes
o	Eggs

•	🧮 Automatic Total Calculation: Computes total bill based on entered item quantities and their predefined prices.

•	♻️ Reset Functionality: Quickly clears all input fields.

•	🪟 User Interface: Clean and intuitive GUI layout using Frames and Labels.

________________________________________

🔧 Technologies Used

•	Python 3

•	Tkinter (Standard Python GUI Library)
________________________________________

🚀 How to Run

1.	Ensure Python is installed on your system.
2.	Clone this repository or download the .py file.
3.	Run the script using:
      python bill_management.py
