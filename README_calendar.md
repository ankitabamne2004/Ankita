📅 Calendar GUI Application (Tkinter)

This is a simple yet interactive GUI-based Calendar application built using Python's tkinter and calendar modules. It allows users to select any month and year and instantly view the corresponding calendar in a user-friendly interface.


________________________________________
💡 Features

•	Select any month and year using spinboxes
•	View the full calendar for the selected month/year
•	Clean and minimal Tkinter interface
•	Dynamically updates calendar view on button click
•	Easy-to-understand Python source code — great for beginners!


________________________________________
🛠️ Technologies Used

•	Python 3

•	Tkinter – for GUI development

•	calendar – built-in Python module to fetch monthly calendars


________________________________________
🧠 How It Works
•	Users choose the month (1–12) and year (1999–2100) via Spinbox widgets.
•	On clicking "Show", the application uses calendar.month(year, month) to fetch the calendar.
•	The result is displayed inside a Tkinter Text widget.
